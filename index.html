BOSS LEVEL • PROJECT DEEP DIVE

VULNERABILITY TRACKER: HOW IT WORKS

The application separates the user interface, API and persistent storage. The desktop client communicates with FastAPI over HTTP; it does not connect directly to PostgreSQL.

DESKTOP CLIENTPython · tkinter
HTTP / JSON ↕
REST APIFastAPI · Pydantic
SQL ↕
DATABASEPostgreSQL

DATA MODEL

Team is responsible for multiple Assets. A Finding links an asset to a Vulnerability and stores status, discovery date, due date and resolution date.

API CAPABILITIES

List and filter findings, retrieve an individual finding, list assets and teams, view unresolved findings grouped by severity, create findings and update their status.

VALIDATION & TESTING

Database constraints protect data integrity. Write endpoints require an API key; request data is validated with Pydantic. Automated tests cover API availability, authentication, validation and data operations.

Project details are based on the THGA term-project documentation. Course concepts and examples were adapted and extended for the application.
