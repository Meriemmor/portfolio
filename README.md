# Meriem.exe — Portfolio

Personal portfolio of Meriem Mornagui, an Bachelor of Engineering (B.Eng.) student in Informationstechnik und Digitalisierung at Technische Hochschule Georg Agricola and Working Student in IT & Business Analytics at E.ON Digital Technology.

## Run locally

This is a static HTML/CSS/JavaScript website. No build step is required.

1. Download or clone this repository.
2. Open `index.html` in a browser, or serve the folder with a local static server.
3. Keep `player-meriem.png`, `style.css` and `script.js` in the same directory as `index.html`.

## Featured projects

- **Vulnerability Tracker:** Python, FastAPI, PostgreSQL, SQL, Docker Compose, tkinter and pytest. [Repository](https://github.com/Meriemmor/DBMS_10) · [Demo video](https://www.youtube.com/watch?v=9EdNiDMKFo4)
- **ESP32 OTA Update System:** Arduino/C++, ESP32, Wi-Fi, HTTP and GPIO.
- **ROS2 LaserScan Publisher:** Python, ROS2 and `sensor_msgs/LaserScan`.
- **Mobile Notes Application:** requirements engineering, use cases and software design.
